# Website-first scope

The supplied application document defines five modules, including a later mobile application phase. For this delivery, the first three web-relevant modules are implemented and the mobile application is deferred.

## Implemented website scope
- Resident / society / emergency contact management
- SOS and emergency notification management
- Guardian escalation and community response
- Authentication, registration, profiles and password flows
- Admin user and guardian verification
- Emergency history, filters, search, priority, GPS/map view
- Availability-based responder assignment
- Audit/response history and response-time analytics
- In-app notifications with read/unread state
- Optional realtime WebSocket channel with polling fallback
- Email/SMS/push integration points for the website
- Responsive UI and dark mode

## Deferred
- Native Android/iOS application
- Mobile-only testing and documentation
- User-selected features 14 and 15
